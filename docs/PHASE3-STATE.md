## 六、C3 的盲区与它放过的东西

C3 只扫 `.md`，所以 `.py` 与 `.json` 里的中文它看不见，
且它只扫 `Assets/skills/*-en/`，根目录文件与 `tools/` 完全在扫描范围之外。

### 这个盲区放过了一个真缺陷

`full-chain-testing-en/scripts/knife1_spec.py` 的正则**只匹配中文任务标签**
（`[依赖]`、`[FR 来源]`）——**它解析不了英文版流水线产出的 tasks.md**。

这不是文案残留，是**功能缺陷**：英文链路的通路挖掘会漏掉全部跨 feature 依赖边。
已修为匹配英文标签。
